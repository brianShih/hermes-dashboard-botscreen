# Bot Screen UI / UX

版本：0.3.0。此文件描述 Dashboard plugin 的介面契約，原生 Electron UI 不在範圍內。

## 操作順序

| 狀態 | 主要操作 | 呈現 |
|---|---|---|
| 尚未啟動桌面 | 啟動並觀看 | 說明隔離環境與預設觀看模式 |
| 桌面已啟動、畫面未連接 | 觀看畫面 | 一個主要按鈕，避免與維護工具競爭 |
| 觀看中 | 接管操作 | 顯示尚未開放鍵盤滑鼠 |
| 人工操作中 | 交回控制權 | 琥珀色提示、桌面外框與控制狀態文字 |
| Hermes 連線中斷 | 重新連線 | 說明人工控制權不會自動交回 |
| 畫面中斷／逾時 | 觀看畫面 | 明確重試，重新取得單次 ticket |

重新連線、狀態更新與單獨啟動桌面屬次要工具，放在「更多操作」。人工操作中禁止從該選單重新連線，以免意外中斷操作流程。

## 視覺與可及性

- 沿用目前 Hermes 深色環境，暖白文字、低彩度綠色連線點、琥珀色人工控制狀態。
- 強調一個主要動作；不以顏色作為唯一狀態線索。
- 桌面區填滿剩餘空間，保持遠端畫面比例，不改變 framebuffer 或裁切桌面。
- 文字最小 12px，手機操作目標至少 44px；所有操作使用原生 button。
- 維持可見的鍵盤焦點；「更多操作」支援 Enter、Tab、Escape 與外部點擊關閉。
- 全螢幕不改變控制權。拒絕全螢幕要求時，不撤銷原本有效的人工輸入狀態。
- 支援 reduced motion，動畫只用於等待狀態與輕微操作回饋。
- 狀態訊息使用 polite live region；圖示為裝飾，不重複朗讀。

## 邊界

- 前端觀看模式不能取代後端 lease 與 RFB input filter。
- 只有明確接管成功才開放輸入，任何重連都先回觀看模式。
- 畫面連線等待最多 15 秒，逾時提供重試，不無限等待。
- CSS 嵌入單一 bundle 並使用 `bs-` 前綴，不修改 Hermes 的認證、遙測選擇或全站樣式。

實測與截圖見 `evidence/ui-review.json`、`evidence/UI_UX_REVIEW.md`。宿主首次使用提示在窄螢幕可能佔用較多高度，plugin 提供有文字的全螢幕入口；不替使用者選擇宿主遙測選項。


## 多國語言（v0.4.0）

Bot Screen 支援繁體中文、簡體中文與 English。進入 Bot Screen，開啟右上角「更多操作（•••）」→「語言」，選擇語言或「跟隨 Hermes」。預設跟隨 Dashboard 的語言設定；不支援的語言回退英文。沒有宿主語言時才參考瀏覽器語言。

語言偏好只儲存在目前網站的瀏覽器 localStorage（`bot-screen:language:v1`），不修改 Hermes 的語言、帳號或隔離 profile。切換語言會立即更新按鈕、輔助標籤、狀態與已顯示的訊息，保留現有桌面連線及控制權。已知前端錯誤有翻譯；後端原始錯誤保留在本地化提示中，方便排查。

翻譯檔位於 `bot-screen-plugin/src/locales/`，語言解析及回退邏輯位於 `src/i18n.mjs`。新增語言時補齊相同訊息鍵與參數，再加入語言清單及別名解析，執行單元測試與建置。沒有新增執行期套件。

多國語言前端與 Windows／Docker 後端修正已安裝到日常 Dashboard（9119），並通過真實畫面、接管／交回與三輪異常斷線重連驗收。隔離 Linux Dashboard（9124）回歸通過；跨平台範圍與安裝方式見 CROSS_PLATFORM.md。
